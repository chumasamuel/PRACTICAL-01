# Department of Computer Science Website

## University of Kerala

This is a student web development project for a **Department of Computer Science website at the University of Kerala**.

The project is being developed using **HTML, CSS and JavaScript** as part of an academic practical project.

> This is an academic/student project and is not the official website of the University of Kerala.

---

## About the Project

The main purpose of this project is to create a simple, modern and responsive website for a Computer Science Department.

The website will provide information about:

* Department
* Courses
* Faculty
* Research
* Admissions
* News
* Extension activities
* Contact information

Some pages have already been developed, while other pages are still under development.
